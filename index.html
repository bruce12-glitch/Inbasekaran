Research

My research.

I’m interested in how language models use time and memory. My work focuses on context pruning, KV-cache management, and the information theory behind those choices. I also work on zero-trust software verification.

01 CONTEXT PRUNING

EntroPrefill ↗

Rényi-Guided Context Pruning with Conditional Stability Guarantees for Retrieval-Augmented Generation

Inbasekaran S
arXiv:2610.09757v1 [cs.LG] · Oct 2026 -43.1% TTFT Read paper ↗ Google Scholar ↗

I study which parts of a long context can be removed while an LLM is still processing the prompt. EntroPrefill uses Rényi entropy to propose what to prune, with checks on the attention mass that is removed.

Technical notes ＋
  • I implemented a training-free context-pruning method that reduced time to first token (TTFT) by 43.1% in the reported experiments.
  • The scoring uses Order-2 Rényi entropy on GQA-pooled attention, alongside conditional transformer perturbation bounds.

02 KV-CACHE MANAGEMENT

Page-EntroKV ↗

Hardware-Aligned, Entropy-Weighted KV-Cache Eviction under Grouped-Query Attention

Inbasekaran S
arXiv:2610.03135v1 · Oct 2026 UOR 1.000 · 100% Needle Recall Read paper ↗ Abstract ↗

I work on how an LLM should use a limited KV cache. Page-EntroKV scores and evicts memory at the page level, matching the layer, group, and page units used by serving systems.

Technical notes ＋
  • The framework keeps the Union Overhead Ratio (UOR) at 1.000. Head-independent replay used up to 4.75×–5.1× as much cache on Qwen2.5-1.5B-Instruct.
  • It removes a 13× attention-sink masquerade and reaches 100% needle recall at a 20% KV budget in the reported test; arithmetic-mean pooling reaches 0%.
  • Page allocation uses Rényi-2 collision entropy and Hamilton–Hare largest-remainder rounding.

03 SOFTWARE VERIFICATION

VendorChain

Zero-Trust B2B Supply-Chain Verification Engine

Inbasekaran S · Undergraduate Research Opportunities Program (UROP) at SRMIST
UROP Research Zero-Trust & Cryptography

I built VendorChain to check software as it moves through a supply chain. It combines zero-trust file intake, signed software bills of materials, and a private blockchain record of verification decisions.

Technical notes ＋
  • I built a NIST SP 800-207-aligned intake pipeline with binary magic-byte validation, AES-256-GCM envelope encryption, and in-memory zeroing.
  • I used Syft to extract CycloneDX software bills of materials and Cosign to sign them, so an artifact’s origin and integrity can be checked.
  • I deployed a private Hyperledger Fabric network with Go chaincode to record SHA-256 artifact hashes, policy decisions, and timestamps.
