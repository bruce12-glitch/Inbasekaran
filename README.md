# Inbasekaran S — Research portfolio

A responsive portfolio for AI systems and LLM inference research, with an editorial layout, light pastel surfaces, and locally hosted Inter typography.

Live site: https://bruce12-glitch.github.io/Inbasekaran/

## Structure

- `index.html`: portfolio content and accessible native disclosures.
- `assets/studio.css` and `assets/studio.js`: responsive presentation, navigation, and copy-email controls.
- `assets/studio/`: two supplied illustrations and original section mascot artwork.
- `assets/mascots/studio-*`: optional mascot interactions and motion controls.
- `assets/fonts/`: locally hosted Inter fonts and their license.
- `assets/inbasekaran-portrait.jpg`: permanent portrait, using the supplied photograph.
- `brand-system/`: palette, typography, spacing, imagery, and accessibility references.

All contact actions use `mailto:inba.research.ilrl.labs@gmail.com`.

GitHub Pages serves the root directory of `main`. No build step is required. Asset links are relative for compatibility with repository Pages URLs and custom domains. The core page and native disclosures work without external libraries. Optional decorative sparkles use Lottie; a 3D character renderer loads only when requested, with the original illustration as its fallback.

The page uses light backgrounds throughout, visible keyboard focus indicators, a skip link, reduced-motion support, a motion pause control, and layouts for mobile, tablet, and desktop. Research descriptions and accomplishments are retained from the original portfolio. Illustration usage is deliberately limited to the opening portrait, the research sketch, and optional section guides.
