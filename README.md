# Inbasekaran S — Research portfolio

A responsive, dependency-free portfolio for AI systems and LLM inference research.

Live site: https://bruce12-glitch.github.io/Inbasekaran/

## Structure

- `index.html`: content, responsive styles, and optional appearance/copy-email controls.
- `assets/inbasekaran-portrait.jpg`: permanent portrait, using the supplied photograph.

All contact actions use `mailto:inba.research.ilrl.labs@gmail.com`.

GitHub Pages serves the root directory of `main`. No build step or third-party scripts are required. Asset links are relative for compatibility with repository Pages URLs and custom domains.

The page includes light and dark appearances, keyboard focus indicators, a skip link, reduced-motion support, and a mobile layout. Research descriptions and accomplishments are retained from the original portfolio.
